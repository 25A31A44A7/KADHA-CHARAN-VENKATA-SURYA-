TECH QUIZ PRO

Tech Quiz Pro is a sleek, interactive technology quiz game built using HTML, CSS, and JavaScript. It challenges your tech knowledge with a smooth user experience.

FEATURES:
•20 Dynamic Questions across various topics
•3 Difficulty Levels (Easy, Medium, Hard)
•Real-time Feedback on every answer
•Instant Score Tracking shown at the end

TECHNOLOGIES USED:
•HTML for the skeleton
•CSS for the modern UI
•JavaScript for the game engine

EDITOR:
Developed using Spck Editor (Mobile).

How To Run
Open index.html in any web browser to start.
